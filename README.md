Автоматизированная система распознавания вокала для караоке на базе **Faster-Whisper**. Проект оптимизирован для работы с "грязным" вокалом (после разделения трека через Demucs) и поддерживает пословную синхронизацию.

## Основные возможности
- **Пословные таймстемпы:** Точная привязка каждого слова к временной шкале (Word-level timestamps).
- **VAD (Voice Activity Detection):** Фильтрация тишины и фоновых шумов для предотвращения галлюцинаций нейросети.
- **Мультиязычность:** Поддержка 8 языков (FR, IT, RU, EN, PT, ES, JP, PL).
- **Автоматическая оценка:** Встроенные инструменты для расчета точности (WER/Accuracy) на основе эталонных текстов.

## Технический стек
- **Base Image:** NVIDIA CUDA 12.0.1 (Runtime Ubuntu 22.04).
- **Engine:** Faster-Whisper (Model: Medium).
- **ML Libraries:** CTranslate2, PyTorch, JiWER.

## Предварительные требования
Для корректной работы с использованием видеокарты (GPU) вам понадобятся:
1. **Docker** и **NVIDIA Container Toolkit**.
2. **NVIDIA GPU** (рекомендуется от 6 ГБ VRAM).
3. Установленные драйверы с поддержкой CUDA 12.

## Инструкция по сборке и запуску

### 1. Подготовка данных
Создайте папку `data` в корне проекта и разместите там аудиофайлы в формате `.m4a`, разделенные по языковым папкам:
```text
/data
  /RU
    song1.m4a
  /EN
    track2.m4a
```
### 2. Сборка Docker-образа
Соберите контейнер, который установит все необходимые зависимости и настроит среду CUDA:

```bash
docker build -t music-whisper .
```
### 3. Инструкции по запуску
Интерактивная обработка трека (app.py)
Используйте этот скрипт для распознавания конкретного аудиофайла. Модель medium выполнит транскрибацию с применением VAD-фильтра для очистки от шумов.

```bash
docker run --gpus all -v ./data:/data -it music-whisper python3 app.py
```
Результат: Пословные таймстемпы выводятся напрямую в консоль.

Массовое тестирование датасета (benchmark.py)
Запустите этот скрипт для автоматической обработки всех языковых папок (RU, EN, JP и др.).

```bash
docker run --gpus all -v ./data:/data -it music-whisper python3 benchmark.py
```
Особенности:

1. Если файл .txt с эталонным текстом отсутствует, система автоматически создаст его как черновик.
2. Еcли эталон есть, будет выведен расчет точности для каждой песни и итоговая таблица по языкам.
